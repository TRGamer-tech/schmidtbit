# Malerei & Lehmbau Daniel Kohlbrenner, Thun · Website-Entwurf

Statische Website (HTML, CSS, Vanilla JS), gebaut von [SchmidtBit](https://schmidtbit.ch). Bereit für Cloudflare Pages.

- Kein Build-Schritt: Root-Verzeichnis dieses Branches direkt deployen.
- `_headers` enthält Sicherheits- und Cache-Header. Für die Kunden-Vorschau den auskommentierten `X-Robots-Tag: noindex`-Block aktivieren.
- Bilder: KI-generierte Symbolbilder (Gemini) als responsive WebP in `assets/img/`. Vor dem Livegang durch echte Fotos ersetzen oder als Symbolbilder gekennzeichnet lassen.
- Offene Platzhalter auf der Startseite (gelb markiert): angebotene Farbtöne und Systeme, Ausbildung und Erfahrung, echte Projektfotos.
- Die Domain `kohlbrenner-lehmbau.ch` in Canonical, OG-Tags, Sitemap und JSON-LD ist ein Vorschlag. Vor dem Livegang Verfügbarkeit prüfen und überall ersetzen.
